# 星図生成プログラム (seizu)

指定した場所・日時の全天または特定方向の星図を PNG/JPG 画像として出力します。  
**デスクトップ GUI**（tkinter）と **ウェブアプリ**（Streamlit）の両方で動作します。

---

## ファイル構成

```
core.py   — 星図生成ロジック（GUI・ウェブ共通ライブラリ）
gui.py    — デスクトップ GUI（tkinter）
streamlit_app.py    — ウェブアプリ（Streamlit）
```

---

## 必要環境

| 項目 | バージョン |
|------|-----------|
| Python | 3.11 以上 |
| [uv](https://docs.astral.sh/uv/) | 最新版推奨 |

依存ライブラリ（uv が自動インストール）: `astropy`, `matplotlib`, `numpy`, `streamlit`, `tzdata`

---

## セットアップ

```bash
git clone <repo-url>
cd seizu
```

初回起動時にカタログデータ（恒星・星座線）をネットからダウンロードして  
`~/.seizu/` にキャッシュします（数十秒かかります）。

---

## 起動方法

### デスクトップ GUI

```bash
uv run gui.py
```

設定パネル（左）で各種オプションを選択し、「★ 星図を生成」ボタンを押すと  
右のプレビューエリアに結果が表示されます。  
追加の依存ライブラリは不要です（tkinter は Python に標準搭載）。

### ウェブアプリ（ローカル）

```bash
uv run streamlit run streamlit_app.py
```

ブラウザで `http://localhost:8501` を開きます。  
サイドバーで設定を調整し「🌟 星図を生成」ボタンを押すと、ブラウザ上で確認・ダウンロードできます。

## Streamlit Community Cloud へのデプロイ

GitHub リポジトリに push するだけで無料でウェブ公開できます。

1. このリポジトリを GitHub に push
2. [share.streamlit.io](https://share.streamlit.io) にアクセスし GitHub アカウントでログイン
3. **New app** → リポジトリ選択 → Main file: `streamlit_app.py` → **Deploy**

`packages.txt`（`fonts-noto-cjk`）により、Streamlit Cloud の Linux 環境でも日本語フォントが使用されます。

## 設定項目

GUI・ウェブアプリ共通で以下の設定が可能です。

### 観測地

| 項目 | 説明 |
|------|------|
| 都市 | プリセット都市から選択（→ [対応都市一覧](#対応都市一覧)） |
| 緯度 / 経度 | 手動入力も可能 |
| タイムゾーン | IANA タイムゾーン名 |
| 地名 | タイトルに表示する名前 |

### 日時

| 項目 | 説明 |
|------|------|
| 日付 / 時刻 | 観測日時（現地時刻）。未指定時は実行時刻を使用 |

### 表示設定

| 項目 | 説明 |
|------|------|
| 言語 | `ja`（日本語）/ `en`（英語） |
| 方向 | 全天 または 8 方位の半円星図（→ [方向指定モード](#方向指定モード)） |
| 限界等級 | 表示する星の暗さの上限（既定 5.5）。値を大きくすると暗い星まで表示 |
| 天の川 / 星座線 / 星座名 / 恒星名 / 惑星名 / 季節の大図形 | 各要素の表示 ON/OFF |

### 出力設定

| 項目 | 説明 |
|------|------|
| DPI | 解像度（72 / 96 / 150 / 200 / 300）。300 で印刷用高解像度 |
| 形式 | PNG / JPG |

## 方向指定モード

特定方向の半円星図を生成します。  
指定した方向が中央下（地平線上）に配置され、天頂が上端になります。

| 日本語 | 英語 | 方位角 |
|--------|------|--------|
| 北 | N | 0° |
| 北東 | NE | 45° |
| 東 | E | 90° |
| 南東 | SE | 135° |
| 南 | S | 180° |
| 南西 | SW | 225° |
| 西 | W | 270° |
| 北西 | NW | 315° |

## 表示内容

### 星

- **HYG データベース v4.1**（約 8,900 星、6.5 等まで）を使用
- **恒星名**: 1 等星以上（約 20 星）のみ表示。日本語モードではカタカナ名（シリウス、ベテルギウス等）を使用

### 天の川

銀河面のランダムサンプリング（17,000 点）を 2D 密度マップに変換し、  
ガウシアンぼかしをかけて自然な輝きを再現します。

### 惑星

月・水星・金星・火星・木星・土星を表示。  
月は大きな円形マーカー、その他はひし形マーカーで描画。

### 星座線・星座名

**Stellarium** のモダン星座データを使用（88 星座）。

### 季節の大図形

| 名称 | 構成星 |
|------|--------|
| 春の大曲線 | アリオト・ミザール・アルカイド・アークトゥルス・スピカ |
| 春の大三角 | アークトゥルス・スピカ・デネボラ |
| 夏の大三角 | ベガ・デネブ・アルタイル |
| 秋の大四辺形 | マルカブ・シェアト・アルフェラッツ・アルゲニブ |
| 冬の大三角 | シリウス・ベテルギウス・プロキオン |
| 冬の大六角形 | シリウス・リゲル・アルデバラン・カペラ・ポルックス・プロキオン |

## キャッシュ

初回起動時に `~/.seizu/` へ以下のデータをダウンロード・保存します。

| ファイル | 内容 | ソース |
|---------|------|--------|
| `hyg.pkl` | HYG 恒星カタログ（約 8,900 星） | astronexus/HYG-Database |
| `constellations.pkl` | 星座線データ（88 星座） | Stellarium skycultures |
